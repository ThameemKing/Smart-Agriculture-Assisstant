# IoT Domain Analyst Project

This project contains research, analysis, and reports related to IoT (Internet of Things) domain analysis as part of SEM-8 coursework.

## Project Structure

- `CORRECTED_LITERATURE_SURVEY.md` - Literature survey with corrections and findings
- `FINAL_REPORT_AUDIT_REVIEW.md` - Final audit review report
- `generate_report.py` - Script to generate reports
- `generate_full_report.py` - Script to generate comprehensive reports
- `create_startup_ppt.py` - Script to create presentation decks
- `stack.txt` - Technology stack information
- `Steps to run.txt` - Instructions for running the project

## Getting Started

1. Clone the repository
2. Install required dependencies
3. Follow the instructions in `Steps to run.txt`

## Usage

Run the respective Python scripts to generate reports and presentations:

```bash
python generate_report.py
python generate_full_report.py
python create_startup_ppt.py
```
